# Read only when MATRIX_SKIP names this file. ci.yml sets it on push and omits it on
# schedule and workflow_dispatch, so the weekly run builds everything.
#
# THE BAR FOR BEING IN HERE is not "slow". It is that the recipe's failure mode is
# EXTERNAL -- something outside this repository breaks it -- so a per-push run converts
# someone else's change into a red master, at a cadence where we cannot act on it anyway.
# A recipe that is merely expensive stays in: cost is not a reason to stop checking.
#
# Measured on debian-64bit, run 9907ed3, 2026-09-17, with nothing skipped: 33 recipes in
# 1315 s. all-browsers was 456 s of that, tor-browser 92 s and firmware-refresh 92 s; the
# other 30 recipes came to 662 s between them, at a median of 6 s each. The matrix prints
# each recipe's seconds, so these numbers can be re-measured rather than remembered.

tor-browser   weekly, not per-push: a version-pinned 138 MB tarball from dist.torproject.org is an external dependency, and a Tor Browser release would redden master
